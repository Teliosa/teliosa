# Exemple Teliosa : quatre semaines de suivi d’activité

L’[exemple commenté sur quatre semaines](quatre-semaines-commentees.md) montre comment lire un suivi d’activité et relier ses observations à des actions concrètes.

Les données sont fictives : elles servent à comprendre l’utilisation du tableau, pas à présenter les résultats d’un client Teliosa.

Pour travailler sur votre propre activité, téléchargez le [tableau Excel](../ressources/tableau-suivi-activite.xlsx?raw=true) et consultez son [mode d’emploi](../guides/suivre-son-activite.md).
