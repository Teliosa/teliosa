# Ressources Teliosa pour coachs et thérapeutes

Trois outils gratuits pour faire le point, suivre votre activité et préparer votre visibilité locale.

| Ressource | À quoi sert-elle ? | Accès |
|---|---|---|
| Diagnostic d’activité | Choisir une priorité et définir trois actions, avec un exemple rempli. | [Ouvrir la fiche](diagnostic-activite.md) |
| Tableau de suivi d’activité | Suivre les demandes, rendez-vous, séances et encaissements semaine après semaine. | [Télécharger le fichier Excel](tableau-suivi-activite.xlsx?raw=true) |
| Kit fiche Google | Préparer les informations, la description et les photos de votre fiche professionnelle. | [Ouvrir le kit](kit-fiche-google.md) |

Pour commencer, choisissez l’outil qui correspond à votre besoin. Copiez les fiches dans votre outil de notes ou téléchargez le tableur pour le remplir dans votre espace privé.

Le tableau est accompagné d’un [mode d’emploi](../guides/suivre-son-activite.md) et d’un [exemple commenté sur quatre semaines](../exemples/quatre-semaines-commentees.md).
